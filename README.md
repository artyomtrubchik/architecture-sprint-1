# Задание 1:

## Уровень 1.
Для реализации микрофронтедной архитектуры мы будем использовать vite и vite-plugin-federation https://github.com/originjs/vite-plugin-federation. Vite предлагает более простую настройку и использование, а также сокращает время сборки проекта по сравнению с webpack. 

## Уровень 2. 
Структура проекта:
- Хост - это основной проект, который будет запускаться и управлять микрофронтендами, подтягивая их в проект.

Микрофронтенды:
- auth - авторизация и регистрация
- profile - редактирование профиля пользователя. В целом его можно было бы сделать в проекте с авторизацией, но если у нас достаточно большое количество пользователей, и мы хотим сделать проект более масштабируемым, то лучше сделать отдельный микрофронтенд для профиля.
- places - список мест, которые можно добавлять, редактировать и удалять.
- shared - общие компоненты, которые можно использовать в других микрофронтендах. Например, попап PopupWithForm используется в auth при редактировании профиля и в places при добавлении нового места.

Итого, у нас будет 4 или 5 проектов, в зависимости от доступных ресурсов команды.
В папке frontend-new представлена новая структура проекта, которая будет использоваться для реализации микрофронтедной архитектуры.
